# פותר קוביה הונגרית עם תמונות

כלי ווב שפותר קוביה הונגרית שעל המדבקות שלה יש תמונות: לא רק שכל פאה תהיה בצבע אחד, אלא שכל התמונות יעמדו באותו כיוון.

1. מצלמים 6 פאות לפי הדמיה תלת־ממדית שמראה איך לסובב את הקוביה.
2. המערכת מזהה צבע וכיוון של כל מדבקה (אפשר לתקן בנגיעה).
3. מבצעים את הפתרון צעד אחר צעד: סידור החלקים ואז יישור המרכזים.

הכלי כולו בקובץ `index.html` אחד. קוד המקור ב־`src/`. ספריות: three.js, cubejs.
